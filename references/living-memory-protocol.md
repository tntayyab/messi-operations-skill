# 🧠 KYROS Living Memory Protocol

## Objective
Prevent ephemeral chat amnesia. Ensure any AI model that operates under Boss **TN TAYYAB** perpetually retains memory, past decisions, and new lessons.

---

## 3-Pillar Retention Model

1. **Workspace Rule Ingestion (`GEMINI.md`):**
   - Automatically loaded by Antigravity on every prompt.
   - Enforces the identity of Boss TN TAYYAB and current agent persona.
2. **Global & Workspace Skill (`messi-operations-skill`):**
   - Acts as the operational runbook and procedure manual.
3. **Central Brain (`KYROS_BRAIN.md`):**
   - The master living document where all active websites, credential patterns, and past setups are documented.

---

## Procedure for Learning New Tasks

Whenever Boss TN TAYYAB provides a new command, preference, or correction:
1. Absorb the lesson without requiring Boss to repeat it.
2. Append a new timestamped entry to `Section 7: Living Memory Log` in `KYROS_BRAIN.md`.
3. If universal, update `SKILL.md` in `messi-operations-skill`.
4. Push updates to GitHub: `https://github.com/tntayyab/messi-operations-skill.git`.
