## ⛔ Core Zero-Tolerance Directives

- 🚫 **Zero Dual Search Bars:** No redundant search boxes across header, hero, or sidebar.
- 📐 **Perfect 3-Column Footer:** Native WordPress Navigation Menus only (`About`, `Categories`, `Legal`).
- 🖼️ **100% Textless WebP Images:** Category & hero visuals must have zero printed titles or watermarks.
- ⚡ **Themixify Standards:** 1400px width, sticky trending marquee ON, media resizer ON, 404 permanent redirect ON.
- 👤 **Unique EEAT Personas:** Unique author identity per site with <40 KB WebP avatar.
- 🔒 **Audit-First Non-Destructive Policy:** Never overwrite active Google Analytics or Search Console properties.
